# Как работать с лабораторным сайтом

1. Выберите назначенный преподавателем вариант и работу.
2. Нажмите «Скачать лабораторную работу».
3. Распакуйте ZIP целиком.
4. Откройте Начните_здесь.html — это задание с данными, примером и шагами, работающее без интернета.
5. Откройте Шаблон_для_заполнения.docx из той же папки в Word или другом редакторе DOCX.
6. Заполните сведения студента и выполните шаги. Сохраните файл с именем из задания.
7. Передайте отчёт способом, указанным преподавателем.

В архиве одной работы есть HTML-задание, DOCX-шаблон и папка «Данные» с CSV. В комплекте студента они распределены по папкам ЛРxx. Кнопок повторного скачивания, ссылок на сайт и служебных файлов в задании нет. Таблицы находятся в задании и в отдельных CSV для работы в Excel. При импорте CSV выберите UTF-8 и разделитель «точка с запятой».

Настройки, тема и инструкция доступны в каталоге. Настройка преподавателя не требуется студенту. Комплекты всех вариантов в настройках предназначены преподавателю; их реестры студентам выдавать не нужно.
