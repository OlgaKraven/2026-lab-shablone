# Шаблон лабораторных работ

Версия 0.1.0 согласована для публикации.

Демонстрация: https://olgakraven.github.io/2026-lab-shablone/

Оформление взято из 2026-OKFKS-lab. Наполнение обезличено: 4 учебные работы, 3 варианта, 2 семестра и 100 баллов. Для новой дисциплины заменяются данные и тематическое изображение, сохраняются общие компоненты.

## Запуск

Node.js 24, npm.

```sh
npm ci
npm run dev -- --port 4175
```

## Изменение курса

- src/config.ts: МДК, дисциплина, слоган, семестры, логотип, маскот, materialsUrl и LMS.
- src/data/labs.json: работы, баллы, задания, таблицы, требования к сдаче.
- src/data/subject-areas.json: варианты и условия.
- src/data/methodology.ts: связи работ, разобранные примеры и подсказки по шагам.
- public/reports: редактируемые DOCX-шаблоны.

Количество работ и семестров, баллы блоков вычисляются из данных; итог курса должен равняться 100. Для каждой новой работы требуется собственный шаблон DOCX и полный набор данных. Исторические пакеты и отчёты ОКФКС удалены из шаблона.
