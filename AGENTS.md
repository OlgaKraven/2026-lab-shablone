# Работа с шаблоном

Соблюдать docs/TEMPLATE_RULES.md, docs/REPORT_TEMPLATE.md и docs/AUTHORING_RULES.md. Актуальные указания пользователя имеют приоритет.

Не включать ссылки на лекции в лабораторные. Сохранять рабочие CSV в архивах, встроенное оформление HTML и условия варианта. Не добавлять служебные файлы в студенческий ZIP. В Word нет внешних ссылок, QR, времени выполнения и чек-листов. При усложнении курса увеличивать содержательный объём CSV вместе с заданиями и критериями по правилам инструкции.

При обновлении проекта использовать существующие учебные стенды как основу, проверять их и дорабатывать под задания; не заменять рабочий стенд без обоснования. См. docs/AUTHORING_RULES.md, раздел 3.4.
